# Brand / 品牌系统

This directory stores PROMPTprompt brand masters and usage rules.

Planned structure:

- `logo/` — PROMPTprompt wordmark masters
- `p2-mark/` — P² compact mark masters
- `guidelines/` — spacing, minimum size, typography and usage rules

Current principles:

- White base / black mark
- Strong negative space
- Typographic hierarchy over decorative graphics
- Small digital environments prioritize recognition
- Avoid generic AI imagery such as glowing particles, neural networks and neon sci-fi motifs
