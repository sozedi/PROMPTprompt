# PROMPTprompt

> AI product, design, research and company memory for PROMPTprompt.

**PROMPTprompt** is an independent AI product and design research studio. This repository is the long-term, versioned home for the company's website, brand system, research, product documents and institutional memory.

**Domain:** `promptprompt.cn`  
**Compact mark:** `P²`  
**Working position:** AI Product & Design Research  
**Visual principle:** restrained, rational, typographic, monochrome-first.

## Repository model

This repository complements our working systems:

- **Notion → Think / Decide** — living company workspace, decisions, tasks and working memory.
- **GitHub → Build / Preserve** — code, brand assets, specifications, research and version history.
- **promptprompt.cn → Publish** — the public-facing expression of selected work.

## Operating rule

Keep the public website simple; keep the internal memory rich.

When a newer decision replaces an older one, preserve the historical record rather than silently deleting it. Git history is part of the company memory.
